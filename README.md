# 🕹️ Street Fighter UNIR - Proyecto HTML & CSS

Este proyecto es una recreación estática de una página web inspirada en el universo de Street Fighter, desarrollada como parte del módulo de HTML y CSS del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM) en la UNIR.

---

## 📌 Objetivos del Proyecto

El proyecto consiste en la creación de una página web con las siguientes secciones principales:

1. **Encabezado con cita**: "To live is to fight, to fight is to live!"  
2. **Tabla de personajes**: con diseño visual atractivo y estructura personalizada.
3. **Formulario de inscripción**: simulando un registro para jugar a Street Fighter.
4. **Publicación en GitHub Pages** para visualización desde cualquier dispositivo.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- Tipografía personalizada: `Street`
- Imágenes de fondo y personajes optimizadas
- Publicación mediante **GitHub Pages**

---

## 💻 Estructura de la web

### 🔹 Cabecera
- Título principal con fuente personalizada "Street"
- Estilo: color `crimson`, tamaño `46px`, centrado

### 🔹 Tabla de personajes
- Dimensiones: `600x800px`, fondo negro
- Borde: `10px outset` con color `rgb(237, 175, 5)`
- Redondeado: `10px`, centrado
- Imagen de fondo: `fondocabecera.jpg`, con `opacity: 0.5` para contraste
- Celdas:
  - Medidas: `40x45px`, borde `2px solid grey`, fondo negro
  - Tipografía "Street", color `darkorange`, texto centrado

### 🔹 Fondo general
- Imagen `fondo2.jpg` fija como fondo de toda la web

### 🔹 Favicon y título de pestaña
- Favicon: `arcade.png`
- Título de la pestaña: *StreetFighter UNIR*

---

## 📋 Formulario de inscripción

Debajo de la tabla, se incluye un formulario con:

- Título: *Formulario de Inscripción para jugar a Street Fighter*
- Tipografía "Street", tamaño `28px`, color `crimson`, centrado
- Formulario:
  - Dimensiones: `600x1100px`
  - Fondo negro, bordes `outset`, radio `10px`
  - Tipografía general: Verdana, `16px`
- `legend`: fuente "Street", tamaño `14px`, color `rgb(237, 175, 5)`
- `textarea`: anchura `560px`
- Botones:
  - Estilo: fondo `crimson`, texto blanco
  - Dimensiones: `200x50px`, redondeo `5px`
  - Fuente "Street", margen izquierdo `65px`, margen inferior `10px`
